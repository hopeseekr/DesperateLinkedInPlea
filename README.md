# A Desperate LinkedIn Plea

Open-source live-action-style music video. Photoreal generated footage, not animation, cut to an original song.

- License: CC-BY-4.0 (Creative Commons Attribution 4.0). Forks and remixes allowed.
- Footage: scene clips in this repo (Git LFS). Clone with `git lfs clone`.
- Audio: `A Desperate LinkedIn Plea.aac` (also exported as `.mp3`)
- Lyrics: timed WebVTT captions, plus `lyrics.txt`
- Project file: `Desperate LinkedIn Plea.osp` (OpenShot). Open it in OpenShot.
- Finished video: https://youtu.be/uTjQ7zwdvz0

To clone:

    git lfs clone https://github.com/hopeseekr/DesperateLinkedInPlea.git
